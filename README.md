# SoulBridge - Mental Health Support Platform

A comprehensive mental health support system built with React and TypeScript.

## 🌟 Features

- **Real-time Booking System** - Automatic status updates for counseling sessions
- **Aasha** - AI Mental health companion chatbot
- **Multi-Role Dashboard** - Tailored interfaces for Students, Counsellors, Admins, and Volunteers
- **Feedback & Rating System** - One-time session ratings and reviews
- **Peer Support Forum** - Moderated community discussions
- **Resource Center** - Curated mental health resources and tools
- **Mental Health Assessments** - Screening tools and questionnaires
- **Emergency Alert System** - Crisis intervention support
- **Admin Analytics** - Real-time user activity and engagement metrics

## 🛠️ Tech Stack

- **Frontend**: React 18.3.1, TypeScript
- **Styling**: Tailwind CSS, DaisyUI
- **Build Tool**: Vite
- **State Management**: React Context API
- **Authentication**: Role-based access control
- **Real-time Updates**: Automatic booking status synchronization

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/a-smirrithi/SoulBridge.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## 👥 User Roles

- **Students**: Book sessions, provide feedback, access resources
- **Counsellors**: Manage appointments, view student feedback
- **Admins**: User management, analytics dashboard, system oversight
- **Volunteers**: Forum moderation, peer support
